# Kuis Praktikum - Pengembangan Frontend To-Do List dengan React.js

Aplikasi To-Do List berbasis frontend menggunakan **React.js** (Vite) dengan pengelolaan data menggunakan **React State** dan navigasi halaman menggunakan **React Router**.

## Fitur Utama
- **Menampilkan Daftar Tugas (`/`)**: Menampilkan judul, status, prioritas, deadline, serta tombol aksi.
- **Melihat Detail Tugas (`/todo/:id`)**: Menampilkan detail lengkap tugas (judul, deskripsi, status, prioritas, deadline).
- **Menambahkan Tugas**: Formulir modal untuk menambah tugas baru beserta umpan balik notifikasi.
- **Memperbarui Tugas**: Formulir modal pada halaman detail untuk mengubah data tugas yang ada.
- **Menghapus Tugas**: Konfirmasi dialog sebelum menghapus tugas beserta notifikasi penghapusan.
